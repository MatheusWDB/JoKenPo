# Sobre o projeto  
**JoKenPo** é um site simples criado como material didático para uma aula de lógica de programação. A aplicação simula o clássico jogo "Pedra, Papel e Tesoura", onde o usuário escolhe uma das opções e o JavaScript seleciona aleatoriamente outra, exibindo o resultado da rodada.

## Funcionalidades:
- Interface intuitiva com três opções: pedra, papel e tesoura.
- Escolha aleatória da jogada do "computador".
- Exibição do resultado (vitória, derrota ou empate).
